# Pressure Points — Beyond the Frame

A scroll-driven, four-act storytelling experience built with Next.js App Router, Tailwind CSS, GSAP ScrollTrigger, and Lenis. Act 1 is implemented; Acts 2–4 are empty sections in the scroll flow, ready for future work.

## Getting started

```bash
npm install
npm run dev
```

Drop the generated portrait at `public/images/portrait.png`. The frame currently renders a subdued CSS fallback until that image is present.

## Checks

```bash
npm run typecheck
npm run build
```
